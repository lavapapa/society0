# 指标与图表

## 一、指标卡（`metric`）

单值与单位、变化、缺值。缺值显示 `—`，不显示 0。来源写在卡片下方。

## 二、时序（`series`）

多序列各自缩放，末值标注；图例给出单位与范围。缺值断线。

## 三、横向条形（`bars`）、分布（`distribution`）、热力（`heat`）

三者都保留原值，颜色只做辅助。热力缺值不参与颜色映射。

## 四、比较（`compare`）

见 `industry.md`。注意基准世界、相对模式与截止日期。

## 五、共用规则

- 单位、口径、来源必须可见；
- 不同量纲不画在同一纵轴；
- 抽样显示要声明，并保留原始明细路径；
- 零、缺、未采集分开。
