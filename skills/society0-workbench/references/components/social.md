# 网络、帖子与曝光

这组组件服务于社交、传播、组织和关系结构。纯呈现，不生成帖子、不调用模型。

## 一、关系网络（`graph`）

```json
{ "nodes": [{ "id": "n1", "label": "凌晨两点半", "group": "用户", "entityId": "actor-lin" }],
  "edges": [{ "source": "n2", "target": "n1", "relation": "关注", "weight": 1 }] }
```

- 节点按 `group` 分组排列，组标题显示在左侧；
- `entityId` 存在时点击节点可定位主体；
- `relation` 形成图层筛选，图例由边类型生成；
- `dashed` 表示弱关系或推断关系；
- 节点大小取 `size`，不表示重要性时留空。

图形连接不自动表示因果。关系类型、方向和权重必须来自资料。

## 二、帖子浏览（`feed`）

```json
{ "posts": [{ "id": "post_1", "author": "凌晨两点半", "at": "2026-05-07", "tick": 1,
  "content": "…", "originalOrder": 0, "scope": "recommended", "replies": [] }] }
```

- **原推荐顺序** 按 `originalOrder` 或数组顺序，不重排；
- 最新发布、回复最多只改变浏览顺序，不改变原顺序记录；
- `scope` 取 `recommended`、`visible`、`all`，用于分别检查推荐池、实际可见与全部帖子；
- 帖子详情显示正文、回复、作者定位与原推荐位次。

推荐顺序、实际注入模型的帖子、轮末新增的互动是三件不同事实，不能相互补算。

## 三、曝光与注入（`exposure`）

| 列 | 含义 |
|---|---|
| 推荐池 | 候选数量 |
| 实际可见 | 当时进入可见范围 |
| 注入模型 | 实际进入模型输入 |
| 轮末新增 | 本轮结束后才产生，不补算为当时已见 |

## 四、规模

节点、边与帖子较多时保持总数与筛选范围可见；正文按需展开。图库与大型力导向布局按需接入，默认采用确定性分层布局，刷新后位置稳定。
