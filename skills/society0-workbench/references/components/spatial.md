# 空间、轨迹、OD 与扩散

## 一、空间图（`map`）

```json
{ "nodes": [{ "id": "n-ningde", "label": "宁德", "x": 120, "y": 80 }],
  "routes": [{ "from": "n-ningde", "to": "n-shanghai", "weight": 2, "failed": false }],
  "missing": [{ "label": "成都仓" }] }
```

- 有坐标的对象按相对位置投影，抽象平面不声明地理比例；
- 无坐标对象列入“缺坐标”，不落在 (0,0)；
- `interrupted` 用虚线，`failed` 用失败色；
- `weight` 表示运量或强度，含义由资料说明。

需要真实底图时另行接入矢量瓦片；默认离线可读。

## 二、轨迹（`track`）

逐时点位置序列，滑块按全轨迹时点推进。图例标出每条轨迹、位置数与当前归属，避免多条线混淆。时间断档保留断点。

## 三、OD 矩阵（`od`）

起点 × 终点，零值保留 0，缺值显示 `—`。不把零流量与未采集混为一谈。

## 四、扩散与群体状态（`diffusion`）

状态定义、颜色、占比与逐时点计数由资料给出。工作台不推断传播机制，也不把相关性画成因果。

## 五、边界

地图、甘特等复杂布局是呈现组件，不参与仿真计算；空间坐标与距离单位由数据适配器负责。
