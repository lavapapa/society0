# 时间与日历

## 一、时间类型

同一次运行可能同时有：

| 类型 | 字段 | 用途 |
|---|---|---|
| 业务时间 | `businessTime` | 日历定位、跨世界对齐 |
| 完整步骤 | `step` / `round` | 轮次轴、检查点 |
| 执行时间 | `executedAt` | 真实运行耗时 |

三者不互相替代。七日一步的仿真可以在一个步骤内包含多个自然日事件。

## 二、观测点

```json
{ "id": "obs-03", "runId": "run-common-01", "step": 3, "businessTime": "2026-05-22", "label": "第 3 步", "availability": "partial" }
```

- `observations[]` 是页面唯一可选择的时点集合；
- 选择以 `id` 保存，刷新后仍能恢复；
- 同一天多个观测点分别列出，由用户决定看哪一个；
- 没有观测点的日期在月历上可见但不可选。

## 三、没有日期映射

抽象回合制实验可能只有 `round`，没有 `businessTime`。此时：

- 日历不可用，界面给出原因；
- 轮次轴正常步进；
- 不要用浏览器当前日期或第一天伪造业务时间。

## 四、数据范围

日期选择的含义是“查看该范围已有的记录”，不是“重建当时世界”。资料只包含事件记录时，就只展示事件与可用的完整点，不凭空生成状态。

## 五、扩展（B6）

后续加入周／日视图、区间选择和事件图层时，继续使用同一 `observations` 选择身份，不另造第二套时间游标。
