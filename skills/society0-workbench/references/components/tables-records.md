# 表、记录与会话

## 一、数据表（`table`）

```json
{ "columns": [{ "key": "units", "label": "数量", "align": "right" }],
  "rows": [{ "id": "r1", "units": "12,400" }],
  "total": 4, "loadedRange": "4 / 4" }
```

- 筛选只影响显示，不改变总数口径；
- `total` 未知时显示已加载数；
- 数字列右对齐，单位写在列名或单元格；
- 长文本列使用详情面板展开。

## 二、记录浏览（`records`）

列表到正文，正文按原文换行呈现。`entityId` 存在时可定位主体。

## 三、完整会话（`thread`）

按 `seq` 顺序显示系统、输入、模型输出与工具结果；`status` 区分完成与失败。长会话保留已显示数与总数。

## 四、文档（`document`）

最小载荷：

```json
{ "id": "ds-doc", "availability": "ready", "title": "设计说明", "source": "用户对话 · 第 3 轮",
  "paragraphs": ["实验问题与背景……", "候选方案与取舍……"] }
```

- `paragraphs` 是正文段落数组，按顺序渲染；缺省时显示“资料待提供”；
- `source` 说明来源（对话轮次、文件、链接），显示在正文下方；
- 标题由面板头承担，正文不再重复标题；
- 需要原文定位或规则出处时，在段落里写“来源：<URL 或记录位置>”，或将证据单独做成 `table` 数据集。

来源引用目前是文字字段，没有独立的 `sourceRefs` 结构；需要结构化索引时用表格列出“条目、来源、日期、强弱”。
