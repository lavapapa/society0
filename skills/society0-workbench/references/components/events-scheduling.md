# 事件、排程与事项

## 一、事件日历（`events`）

```json
{ "events": [{ "id": "e1", "title": "政策公告", "start": "2026-07-16", "layer": "政策" },
             { "id": "e6", "title": "产线检修", "start": "2026-08-10", "until": "2026-08-24", "layer": "资源" }] }
```

- 图层由 `layer` 自动分组，可单独开关；
- 区间事件在开始日记入，`until` 在详情与提示中显示；
- 同一天超过三个事件折叠为“+N”，不丢弃数据；
- 公告、生效、到期等不同含义用图层区分，不用同一颜色混排。

## 二、时间线泳道（`timeline`）

按主体、角色或阶段分组。`at` 为时点，`at`+`until` 为区间。缺失坐标不推测。

## 三、甘特（`gantt`）

- 细条为计划，实条为实际；
- 只有计划时保留计划条，不画完成条；
- `status` 取 `queued`、`running`、`completed`、`failed`、`paused`；
- 实际结束未提供时不用今天补齐。

## 四、事项板（`board`）

按状态分栏，卡片显示负责人与到期。拖动改变状态属于运行操作，本版只读。

## 五、流程（`flow`）

阶段序列与状态：`done`、`current`、`pending`、`blocked`。时间为空显示 `—`，不推断完成时间。

## 六、时间语义

业务日期、阶段与真实执行时间分别保存；七日一步的仿真仍可以在一个步骤内出现多个自然日事件。
