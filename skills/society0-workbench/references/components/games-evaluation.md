# 博弈、评估与诊断

## 一、收益矩阵（`matrix`）

```json
{ "rows": [{ "id": "r1", "label": "维持价格" }], "columns": [{ "id": "c1", "label": "维持价格" }],
  "cells": [{ "row": "r1", "column": "c1", "rowPayoff": "3.2", "colPayoff": "3.2", "note": "共同维持" }] }
```

每格上行是行方收益，下行是列方收益。未定义的格显示 `—`，不补零。收益单位写在数据说明里。

## 二、策略份额（`strategy`）

按回合列出各策略占比。某回合缺某策略时显示 `—`，不插值。

## 三、预测与观测（`forecast`）

- `projected: true` 的序列用虚线；
- `lo` / `hi` 形成区间带，缺失则不画带；
- 误差与基线分别列出，保留评估口径；
- 不把预测值画成已观测事实。

## 四、诊断与用量（`diagnostics`）

激活次数、工具调用、未完成数、调用耗时与结果来自导入资料。页面不发起端点调用，也不把展示数字当作当前服务状态。

## 五、边界

评估口径、基线与评分由使用方提供；工作台只呈现已给结果，不计算研究结论。
