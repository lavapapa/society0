# 指标、比较与产业

## 一、多世界比较（`compare`）

```json
{ "worlds": [{ "id": "world-2pct", "label": "公告后 2%", "isBaseline": true, "through": "2026-12-31",
  "series": [{ "key": "tax", "label": "单位税额", "unit": "元", "points": [{ "t": 1, "v": 2.1 }] }] }] }
```

- 指标由 `series[].key` 组织，切换指标不改变世界顺序；
- `isBaseline` 标记基准世界，相对模式以它为分母；
- 基准为零时不做相对比较；
- 每个世界有各自 `through`，图例标注资料终点；
- 缺指标的世界在下方列出，不补零、不插值。

比较只在共同范围内成立。未覆盖区间留缺口，不用更晚快照填充。

## 二、条形（`bars`）

适合单期横向比较，如各世界累计税额、各企业产量。零值仍画 0，不与缺失混淆。

## 三、分布（`distribution`）

按组给出中位数与四分位区间，并显示样本总数。组内样本过少时仍显示，但需要在来源中说明。

## 四、热力（`heat`）

行 × 列矩阵，颜色按当前范围最小/最大值映射，单元格保留原值。缺值显示 `—`，不参与颜色映射。

## 五、盘口（`orderbook`）

买卖两侧分别列出，数量用条形表示深度。只有一侧时保留另一侧为空，不补造报价。

## 六、产业适配

资金、库存、订单、交易、税务等字段由私有产业适配器提供；通用组件只负责按列呈现与单位显示，不在组件里重建计税或成本规则。
