# 配置与插件

## 一、实验设置顺序

配置目录固定前两项：

1. **插件配置**：机制、参数、依赖与待补字段；
2. **平行世界**：世界计划、来源与参数差异。

后续分区由资料声明（如环境与时间、主体与决策）。前两项即使没有资料也保留入口，显示引导而不是隐藏。

## 二、插件卡片

```json
{ "id": "memory.vector", "label": "向量记忆", "category": "记忆", "availability": "partial",
  "description": "记忆提取、召回与主动工具。", "parameters": 4, "dependsOn": ["cognition.llm"] }
```

- `availability` 为 `ready` 时显示已就绪；`partial`、`awaiting` 提示缺什么；
- `parameters` 缺失时写“参数待补充”，不要显示 0 个参数伪装有配置；
- `dependsOn` 列出依赖，便于发现停用带来的缺口。

展示组件是否加载与仿真插件是否启用是两件事：页面里关掉一个面板不改变实验机制。

## 三、参数编辑

`configFields[]` 声明可编辑字段，编辑器支持文本、数字、布尔、下拉与多行。

- 修改进入当前版本的草稿，不写资料文件；
- 显示原值，便于核对；
- 未发送改动计数，可复制为变更请求；
- 切换版本时草稿按 `configSource` 隔离。

## 四、完整 JSON

需要增删字段时使用 JSON 编辑：

- 保存前必须是合法 JSON；
- 结构错误在本地提示，不写入草稿；
- 编辑后同样生成差异，不直接提交。

## 五、边界

`configFields` 只描述展示与编辑合同。字段是否真正改变仿真，由对应插件和消费者决定；工作台不声称某个字段“已生效”。
