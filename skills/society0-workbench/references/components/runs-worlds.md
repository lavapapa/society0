# 运行、世界与时间

这三类组件把“看哪一次执行”和“看哪个时点”变成明确选择。二者都以稳定 ID 记录，刷新后按 ID 恢复。

## 一、运行选择工作区（WB-02-01 / 02）

顶栏触发器显示当前运行与状态；没有选择时显示“配置视图 · 尚无运行”。打开后有两个视图：

- **运行看板**：每行一条 run，显示世界、版本、状态与资料截至；支持搜索与状态筛选。
- **平行世界**：按 world 分组，run 是可选节点；父世界与来源完整点的关系显示在组标题。

规则：

- 每次运行是独立条目，同一世界的多次运行分别可选；
- 运行状态来自资料，不由界面推断；
- 资料不足的运行仍可进入，详情显示已有与缺失部分；
- 未选运行时保留配置入口，不创建空白运行。

## 二、世界计划（WB-02-04）

配置目录第二项。世界计划可以在运行之前存在：

```json
{ "id": "world-2pct", "label": "公告后 2%", "parentWorldId": "world-base", "plannedSource": "第 10 步完整点", "overrides": { "tax_rate": 0.02 } }
```

子世界缩进显示来源；`plannedSource` 为空时显示“来源待补”。每个世界显示运行数量，可跳到运行页。

世界计划与运行事实分开：计划说明要做什么，运行说明实际执行了什么。

## 三、时间定位（WB-03-01 / 03）

时间模式由资料声明，`round` 与 `calendar` 可以并存。

- 轮次模式按观测点前后移动，不虚构中间步骤；
- 日历模式按月展示有资料的日期，点击日期选择该日观测点；
- 一天多个观测点时列出全部可选，选择其一后在其他组件同步。

没有日期映射时只保留轮次，并说明日历不可用。业务日期、完整步骤和执行时间分别显示，不用更晚的快照补历史。

## 四、交互

- 运行选择器支持 Escape 关闭并返回触发按钮；
- 日历是浮层，默认收起，不遮挡主区；
- 窄屏下运行选择器与日历都以底部弹层出现；
- 选择变化后，主区与左栏同时更新。
