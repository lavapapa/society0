# 渐进资料示例

- 打开：`index.html`
- 资料：`data.json`（mock，revision 4）

展示资料逐步进入后的状态：两个配置版本、五个插件（含待补参数）、四个平行世界、四次运行、五个时点（含同日两个观测点）与主体目录。

阅读路径：

1. 顶部运行选择 → 看板视图，检查每次运行独立列出；
2. 同一工作区切到平行世界视图，看世界分组与来源；
3. 选择“共同历史 A”后，顶部时间选择切到日历，展开月历；
4. 点击 5 月 22 日，检查同日两个观测点的选择。

修改 `data.json` 后：

```bash
python3 ../../../scripts/render_workbench.py --project .
```
