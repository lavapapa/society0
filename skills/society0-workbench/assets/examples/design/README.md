# 设计阶段示例（无运行）

- 打开：`index.html`
- 资料：`data.json`（`dataKind: draft`，revision 2）

只有设计说明、证据与来源、因素表和候选方案；`versions`、`worlds`、`runs` 为空，页面默认进入“观察”，不伪造主体或运行。

阅读路径：

1. 设计说明：问题、本轮锁定项与来源（正文已写来源，页脚不再重复）；
2. 证据与来源：条目、来源与定位、强弱；链接待补时写明“待补”；
3. 设计因素：已选定与待确认分开标记；
4. 候选方案：推荐与候选并列，最终方案仍待用户确认。

渐进更新：在同一 `data.json` 里增加一条来源、一行因素或一段确认摘要，运行 `render_workbench.py --project .` 后刷新；`dataRevision` 递增。
