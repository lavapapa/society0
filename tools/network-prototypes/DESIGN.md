# 网络工作台方案说明

本轮交付三个可操作的桌面布局，供选择 Society0 社交网络工作台的主要阅读方式。样例包含 18 个智能体、6 个帖子、46 条有向关系及配置时点和四个实验时点，全部为合成资料。

## 一、使用

交付文件为 `dist/index.html`，脚本、样式、图标、图形库和数据均已内联。可以用本地浏览器打开，或通过本机 HTTP 预览。当前预览地址为 `http://127.0.0.1:62390/`，服务关闭后该地址失效，HTML 文件可继续保存使用。

底部选择器切换方案；数字键 1、2、3 和左右方向键提供快捷切换。输入框、下拉菜单和详情标签页使用各自的键盘操作。切换方案保留时点、图层、分组、搜索、选中对象和邻域范围，重新创建该布局的画布视口。

建议先选中“林澈”，检查其关联记录，再关闭“关注”图层，切换至“事件追踪”选择一条评论，最后把时间移动到“配置”。这样能比较对象、关系、记录与初始状态的联动。

## 二、方案

三个方案使用相同资料与操作能力，主要差别是阅读入口和空间分配。

| 方案 | 适合的任务 | 取舍 |
| --- | --- | --- |
| 研究台 | 同时核对关系图层、对象与详情 | 操作入口稳定，左右面板占用部分画布；推荐作为默认入口 |
| 探索画布 | 先看全局结构，再逐步聚焦对象 | 收起详情后画布最大；筛选需要展开浮层 |
| 事件追踪 | 从评论、转发等具体记录追溯关联 | 记录到端点的路径短；左栏较宽，适合配合作为分析视图 |

用户选定方向后再整合到正式工作台。配置编辑、实验版本切换、FoV 模块和会话查看沿用上层产品需求，当前原型集中比较网络组件。

## 三、设计

Impeccable 用于建立克制的桌面研究工具视觉层次；Laws of UX 用于固定主要操作位置、保持观察条件及就近呈现详情；Pick UI Library 用于比较图形库与组件成本；Emil Design Engineering 用于按钮反馈、焦点样式和减少动态效果；Prototype 用于隔离方案、统一切换和等待用户选择。

网络采用 Cytoscape.js，选型依据及数据语义见 `SELECTION.md`。三种主体用固定颜色区分，帖子用矩形区分；关系保留类型、方向、端点和时间。位置用于阅读组织，距离没有统计含义。图层过滤、邻域高亮和详情中的关系计数共同依据当前观察范围。

浮动工具条包含放大、缩小、全图、定位、三种布局、重新排列及标签切换。标签与节点保持屏幕可读尺寸；定位使用当前可见邻域。详情可从图上元素、对象列表或事件记录进入。窄窗口将详情移到画布下方。

## 四、验收

本轮已完成构建、数据语义检查、三种桌面布局的浏览器检查，以及 780 像素宽窗口的阅读检查。截图保存在 `.impeccable/review/`。视觉验收修正了标签过小、工具条挤占网络区域及定位留白过大的问题。

源码独立审查修正了隐藏关系参与邻域计算、切换方案丢失观察条件、详情方向键触发方案切换及计数范围不一致的问题。独立 Edge 浏览器验收覆盖搜索、键盘选择、对象与事件详情跳转、邻域、时间和分组筛选、三种布局、缩放及 PNG 实际导出。浏览器控制台无 error，Cytoscape 提示自定义滚轮灵敏度。

验收另发现保持选中后关闭图层会残留邻居高亮，已将高亮和定位统一到当前 graph 数据，移除对样式可见性缓存的依赖。独立复测确认：关闭关注后关系与记录均为零，仅选中对象保留高亮；四项审查问题均通过。对应证据为 `filter-highlight-fixed.png`。

当前样例规模用于判断布局和交互。真实实验数据转换、大规模网络性能与长记录列表虚拟化留待选定方案后，结合实际实验产物确定。

本轮选择的核心问题是：用户应先从对象和关系开始，还是先从具体交互记录开始。推荐以研究台为默认入口，保留事件追踪作为同一工作台的分析视图。
