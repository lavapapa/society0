# 工作台迁移验收

工作台按实验检查、关系网络、帖子浏览组织页面，共享配置版本、试运行与时点。桌面顶栏及页面导航总高 70px；主要内容占据剩余视口，左右栏可收起。

## 一、资料依据

坚果云 Society0 资料目录中找到 `读书会/Demo-新版_通用压缩版.mp4`、`Demo-初版_通用压缩版.mp4`，以及 `汇报 7月24日/society-zero/frontend/app/dashboard/experiment/running/components/structures/network-structure/components/` 下的 `post-explorer.tsx`、`post-card.tsx`、`actor-feed-panel.tsx`。已检查新版视频概览与三个组件源码。帖子浏览采用旧版的用户、发布／信息流、帖子与回复三栏流程，改为精确时点快照与自包含离线呈现。

## 二、功能对应

2026-10-19 视觉重建参考用户提供的 `outputs/lithium-tax-demo-r2-static-fileopen-20260924/index.html`。已实际查看市场总览和主体经营页面，提取 `#f4f7f9` 画布、`#4a8fc2` 强调色、低对比边框、白色圆角面板与紧凑分段标签。工作台保留自身数据模型和交互，主题集中在 `src/theme.css`。用户行 40px、帖子预览 132px；正文与会话使用更大的阅读字号，并支持展开与 Esc 返回。来源、机制阅读说明和完整 JSON 使用折叠呈现。

## 三、数据与边界

社交字段的转换约定见 `skill/references/workbench-guide.md` 的“社交网络与帖子浏览”。正式运行导出器保留现有 Results／Thread 读取链，领域投影由实验转换脚本补充。演示采用单独的合成数据生成脚本 `demo.mjs`，空白模板内没有演示资料。

独立文件使用同一模板与数据，以默认入口区分。页面内草稿跨页面保留；跨文件草稿独立。所有页面检查已保存资料，实验变更继续由研究者复制请求交给 agent 处理。

## 四、验收结果

2026-10-19：模板测试 11 项通过；需要指定历史运行 fixture 的测试本轮未执行。Python HTML 生成器测试 3 项通过，三个 `--view` 入口均生成成功。内置浏览器按 1174×573 视口核对网络、帖子和实验检查，页面主内容从顶部 81px 后延伸到窗口底部。

独立浏览器验收覆盖网络图层、节点及边详情、邻域、布局、缩放、定位、左右栏；帖子作者、信息流、搜索、排序、正文、回复、跨页跳转；历史时点、无运行版本；配置字段和 JSON 修改、变更列表、多次会话、FoV 与全部内置呈现类型。发现网络分组影响帖子作者列表的问题后，拆分筛选范围，复测通过。不同运行使用具有不同正文的合成资料，已验证运行 1 → 运行 2 → 运行 1 的列表与详情内容隔离。

视觉重建后，主智能体走过配置字段修改与差异、关系网络、帖子全文与回复、展开阅读、检查作者、同 tick 第二次会话和展开记录。1186×616 视口下主内容起点为 70px，文档宽高与视口一致。模板测试 11 项通过，1 项历史运行 fixture 测试跳过；skill 结构校验通过。来源折叠和更紧凑的间距已重新构建进空白模板、合成示例和三个入口文件。

这些验收使用合成示例，真实实验与大规模图性能在对应研究接入时验证。原有自定义 renderer 接口保留。

本轮独立复核另外完成网络画布拖动、图片下载、配置 JSON 新增字段与剪贴板请求核对，均通过。完整视觉与交互验收见 [design-qa.md](design-qa.md)。
