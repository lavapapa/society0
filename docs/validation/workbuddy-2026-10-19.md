# WorkBuddy Flash 全流程验证 · 2026-10-19

本轮在 WorkBuddy 普通会话中，以简短自然语言完成新版 skill 更新、社交网络实验配置、真实模型试运行、工作台生成与结果分析。WorkBuddy 负责实验代码与数据转换；维护者通过界面提出研究需求和反馈，必要时修复通用 skill 或模板，再让 WorkBuddy 使用修订版本。

## 一、起点

- WorkBuddy 5.7.3，沿用“安装 Society0 项目 skill 并入门”会话。
- 模型列表提供 Deepseek-V4.1-Flash，用户确认采用该模型。
- 本次更新源为本机 `society0core/skill`，仓库分支 `next`；用户旧实验保留。
- 会话已有旧架构 society0 4.1.14 和规则型起步实验。本轮需要验证 Next skill 与运行环境的一致性。
- 当前属于已有安装、已有会话的更新流程。公开仓库首次安装另见此前记录。

## 二、过程

通过原生 Computer Use 打开 `com.tencent.workbuddy.mac`。模型下拉核对后，在普通输入框粘贴并发送：

> 先更新 Society0 skill：使用本机 /Users/marvin/Documents/同花顺（2）/research/simulation/society0core/skill 。这次按这个版本带我做实验，旧实验保留。更新后告诉我，我们从配置一个小型社交网络实验开始。

### 2.2 研究选择

选择“社区生活谣言”“LLM Agent”“6 人三层链”。提问组件点选后自动进入下一题，末题点选即提交；首次点选后额外点击“下一题”曾跳过第二题，已返回并补选，最终三个答案核对正确。

观察：WorkBuddy 把规则型列为推荐选项，尽管新版 skill 对信息解释、传播与信任优先采用 LLM Agent。本轮明确选择 LLM，保留该偏差供后续引导修订。模型配置沿用已授权的 `society0-workbuddy-test/provider-setup.json`，资料源最后验证日期为 2026-10-02，接入时仍需实际核验；凭据不写入本记录。
