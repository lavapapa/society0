# Society0 5.0.0（未发布）

本分支提供独立进程实时观测与按记录定位的检查点。使用方法见 [运行观测指南](runtime-observation.md)，本次性能与验收证据见 [研究目录](../research/runtime-observation/implementation-plan.md)。该版本尚未发布标签。

## 一、变化

检查点组件采用显式 `sqlite_records_v1` 编码，根状态与增量通过记录位置读取，超大内容支持分段下载。完整 marker 继续决定状态提交，多步骤 epoch 保持原有配置。查询进程通过本地索引提供固定版本分页，Thread 读取不修改原文件，运行状态区分已经提交和已经建立索引的位置。

大表和历史统计使用可分页数据集引用，完整原始内容保留。SimEngine、旧 YAML schedule、StreamingBridge 和专用旧 diff/replay 路径已删除；运行入口为 Society0、CodeSchedule 和代码步骤。

## 二、产物

本版本读取新的记录组件；旧编码产物应使用生成它们的原版本读取与恢复。该分支不提供格式兼容层。跨目录恢复和分叉显式保存来源依赖，离线导出需包含所引用的组件。

正式发布前以确定性测试、独立审查和同规模性能实验共同验收。真实模型和部署文件系统的未覆盖范围在最终验收记录中单独说明。
