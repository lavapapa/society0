社区的不同管理策略对虚假信息核查中数字信任的影响机制
文献综述
（一）社交媒体中的虚假信息（misinformation）传播机制研究
社交媒体中信息传播形态复杂多样，谣言、传言（rumor）、误导信息（disinformation）、虚假信息（misinformation）、假新闻（fake news）等概念交叉出现。尽管概念间有相似之处，但其历史、语境和研究脉络各有不同[ ]。虚假信息概念与社交媒体的兴起和后真相时代的来临有关，强调信息真实性充满不确定，并且注重对其危害的讨论[ ]。本研究采用这一定义，强调信息真实性的客观属性，适用于分析微博等社交媒体中多元信息形态的传播规律与治理路径。
在社交媒体主导信息传播的背景下，虚假信息的影响力愈发显著，已成为学界研究和社会治理的热点议题。虚假信息是信息失实的体现，反映了社会矛盾与大众心理[ ]。数字技术发展使虚假信息生成门槛降低、传播加速，严重威胁公共舆论、社会稳定与用户信任。学界对其定义、类型、传播机制及动因展开多维度探讨。从话语结构演化看，虚假信息已转向社交媒体环境下的自媒体系统生成，呈现核心层、中间层与边缘层的“圈层结构”[ ]。“核链式传播”模型表明，虚假信息在社交媒体上的扩散呈现去中心化、多节点协同转发特征，用户兼具接收者与生产者双重身份[ ]。对微博与推特虚假信息数据的比较研究发现，虚假信息在传播初期（前五小时）即表现出与真实信息明显不同的特征，如更高的传播层级、更广的扩散范围，网络结构呈现典型的“核心—边缘”分层[ ]。
社交媒体平台中的虚假信息已经形成独立话语生态。在意识形态隔离网络中，“同温层”导致虚假信息传播广泛，易形成认知偏见[ ]。虚假信息常通过编造消息源、混用匿名与实名引语来构造“真实性幻象”[ ]，其并非单一源头所能解释，而是权力结构、意识形态、文化认同等多重因素的产物[ ]。虚假信息的判断标准也因此变得相对化，治理难度加大。已有研究从文本风格、传播模式、知识冲突与来源可信度四个维度分析，指出虚假信息语言情绪化、传播快、可信度低[ ]。因此，虚假信息的治理需构建算法透明性和人工编辑机制的平衡体系，以确保公共话语场的公平性[ ]。
（二）社交媒体中的数字信任
随着数字技术与社交媒体平台的发展，公众在信息获取、互动沟通及社会认知等方面越来越依赖数字环境。新技术的发展导致了网络系统和参与者复杂性的不断增加，学者们开始关注新技术对信任的影响，提出了“数字信任”[ ]。数字信任是指使用技术手段建立的全部或部分信任，是基于过去的经验或基于实体已按照或将按照自我陈述的行为行事的证据的信任[ ]。数字信任具有信任的各种特质，也有自身的特殊性，它是以数字技术为中介的综合信任，是人际信任、系统信任与技术信任的综合体[ ]，成为理解数字社会秩序运行机制的关键概念。
“数字信任”不是传统人际信任的简单延伸，而是在高度技术媒介化环境中形成的复合性机制。其结构通常包括以下三个层次[ ][ ]：认知基础是用户对平台功能、内容来源的判断；情感层次是用户对平台、信息发布者的信赖感；制度维度是平台治理机制与透明度如何影响用户预期。
近年来关于虚假信息的研究，主要涵盖虚假信息的类型与传播机制[ ]、用户对虚假信息的感知与认知机制[ ]、社交平台的责任与算法偏见[ ]三个方面。这些研究往往关注的是虚假信息从识别、传播再到干预的逻辑机制，忽视了虚假信息对整个数字信任系统的长期侵蚀作用。用户相信虚假信息，并非单纯的意识形态偏见，而更多是认知惰性所致[ ]。其他研究也发现，信息呈现方式、情绪唤起度以及用户的信息素养水平共同影响其判断。一方面，反复接触虚假信息会导致真相疲劳与信任损失；另一方面，平台若未能有效响应，反而进一步削弱用户对其的信任感。针对虚假信息的治理，当前策略主要集中于事实核查、算法识别与用户教育等维度，但实际效果有限。尤其是在缺乏信任基础的情况下，虚假信息的干预机制常被用户视为“控制”或“审查”。
将“数字信任”引入虚假信息研究，不仅能从微观层面解释用户的信任缺失，还可从宏观层面审视信息社会中信任结构的重建可能，有助于构建传播伦理的新范式，超越“真假辨别”，转向“信任生产”，为信息平台治理提供理论依据，推动算法透明、公信机制建设。
基于此，本研究探究的是受众对虚假信息的数字信任，即微博用户基于虚假信息传播与治理场景形成的综合信任，包括技术信任、系统信任与人际信任。
具体来说，技术信任体现为用户对微博平台虚假信息治理技术体系的可靠性认知，涵盖算法模型（如违规内容识别算法）、数据处理（如谣言传播轨迹分析）、技术响应（如实时拦截虚假信息）及安全机制（如举报信息加密）层面[ ]。用户对虚假信息的技术信任形成，源于对平台技术能否精准识别虚假信息的判断，如相信AI算法能够实时拦截谣言，避免虚假内容扩散。
系统信任体现为用户对微博平台虚假信息治理规则的制度性认同，包括对审核流程透明性、处理标准一致性及治理效能的信任。用户基于《微博社区公约》等公开规则，相信平台能够以统一标准处理虚假信息举报，如对违规账号实施阶梯式处罚，并及时反馈处理结果。
人际信任体现为用户在虚假信息治理场景中对其他主体行为真实性与善意性的判断，包括举报者与被举报者的信任博弈，及用户与围观群体的信任共鸣。例如，用户提交虚假信息举报时，隐含着对被举报内容确实违规的真实性预设，这种预设依赖于对其他用户举报动机的信任，即相信多数举报是基于维护社区秩序的善意。数字信任是拓展的关系信任[ ]。在微博虚假信息治理中，人际信任已突破传统互动局限，用户可能基于对陌生网友历史举报记录的分析，形成对其可信度的虚拟评估，这是数字环境下人际信任的特殊表现形式。

微博平台中的用户关系结构（调节/干预变量）
用户关系指的是用户间通过点赞、评论、分享等互动行为所产生的一种相互关联与影响的关系[ ]。强连接关系（互相关注的好友）表现为用户之间的深入互动和情感联系。这类关系的用户互动频繁，如转发、评论和点赞，促进了彼此之间的信任建立[ ]。弱连接关系（单向关注）则表现为用户一方关注对方，而对方未必回关。这种关系在信息传播中起着桥梁作用，信任度较低，更多依赖于信息的可信度和内容的质量，而非直接互动[ ]。而无连接关系（无关注）则缺乏任何互动或联系，通常信任度较低。通过分析用户内容质量或网络信誉，平台仍可间接推测用户的信任度[ ]。
在微博平台上，用户关系对数字信任的动态变化至关重要。强连接的互关好友通过频繁互动，可能在人际信任维度快速积累信任。这种信任源于对彼此信息真实性的默认认可，如互关用户更易相信对方转发非虚假信息内容。弱连接的单向关注虽互动较少，但独特的信息传递或许会影响技术和系统信任维度，如用户因接收到某大V发布的辟谣信息，进而对微博推荐算法产生技术信任，对此大V用户提升人际信任；无连接的无关注用户间，由于缺乏直接互动，其数字信任更多依赖于平台技术（如虚假信息识别算法）和系统（如微博社区管理中心的举报大厅）提供的间接信任线索。
用户关系网络在增强信息传播的同时也为虚假信息传播提供了有利的土壤，不仅误导公众认知，还可能引发社会恐慌和信任危机[ ]。对于不同的微博用户关系结构，强连接的互关好友间，因信任度较高，虚假信息易被当作真实内容传播，破坏彼此的人际信任，同时用户会质疑微博系统为何未及时拦截此类信息，进而影响对系统审核能力的信任。弱连接的单向关注中，虚假信息可能降低用户对信息可信度的判断，如某单向关注的账号发布虚假信息，用户会认为微博算法未能识别内容真伪，削弱对技术的信任。无连接的无关注用户若频繁接触到虚假信息（如系统推荐的不实内容），会降低对微博技术（如推荐算法）和系统（如内容审核机制）的整体信任。在技术层面，利用AI判定虚假信息，若出现误判（如将真实信息标记为虚假），可能损害用户对技术信任；在平台层面，社区专业管理员判定若效率低下（如长时间未处理举报），会影响系统信任；在用户层面，集体智慧的众包举报形式若存在恶意举报（如用户故意举报真实内容），将影响人际信任。
相反，而不同的社区管理策略在应对虚假信息时，对数字信任的影响也不同。在微博用户关系中，不同结构下数字信任的建立和维持方式不同，也会增强用户的数字信任。强连接的互关好友通过持续的情感互动和信息交流稳固信任，若双方保持信息真实性，且积极参与辟谣信息传播，会增强人际信任。弱连接的单向关注依赖信息价值建立信任，如某单向关注账号持续发布经平台验证的真实性内容，可能提升用户对微博技术（如内容验证算法）和系统（如平台治理机制）的信任。无连接的无关注用户，平台需通过技术手段（如自动标注虚假信息）和系统规则（如置顶辟谣公告）来建立信任。不同的社区管理策略也需要以信任为基础：若用户不信任AI对虚假信息的判定准确性（如误删真实内容），会降低技术信任；若对社区专业管理员处理举报的公正性存疑（如偏袒某类账号），会影响系统信任；若众包举报缺乏公信力（如恶意举报未被处理），将削弱人际信任。

（四）社会模拟仿真相关研究
在数字媒介高度发达的现在，虚假信息的迅速传播与公众数字信任的动摇成为信息生态治理的核心问题。现有研究主要采用内容分析、问卷调查、实验研究与计算传播学方法。内容分析多用于识别虚假信息的语言特征、叙述模式和情感倾向，揭示其如何通过结构与修辞策略操控受众认知。问卷调查法则常被用于测量公众的信任水平与信息感知，评估平台功能、信息来源、隐私保障等维度对数字信任构建的影响。实验研究强调变量控制和因果机制的验证，能够分析特定类型虚假信息在不同语境下对用户行为或信任态度的短期冲击。而近年来兴起的计算传播学方法，依托社交平台数据和算法工具，着重刻画不实信息的传播路径、扩散速度与网络结构，提升了大规模动态数据处理与传播机制建模的能力。
尽管上述方法在机制识别与变量关系分析方面取得了大量成果，但这些方法也存在一定局限。静态分析难以揭示信任的动态演变，微观个体行为与宏观社会结构的连接机制解释力不足。为此，基于代理建模（ABM）的社会模拟仿真方法为信息传播提供了新的研究方向。该方法能够模拟多主体在特定规则下的互动行为，动态展现舆论演化与信息传播的非线性特征，进而为应对虚假信息和维护信任提供更具预测性和干预性的理论支持。
早期研究多采用宏观层面的流行病模型（如SIR模型）模拟信息扩散。近年来，基于代理建模（Agent-Based Modeling, ABM）被广泛用于研究社交网络中的虚假信息传播。通过ABM方法，已有学者模拟社交机器人在“沉默螺旋”现象中的作用，发现仅10%的社交机器人就足以使大多数人沉默，并揭示了连边动态和媒体监管对沉默效应的调节作用[ ]。也有研究模拟新闻推荐平台发现，高自由度算法推荐可能降低“茧房”风险，揭示推荐机制与信任的复杂关联[ ]。
传统ABM依赖于预定义的规则，难以模拟人类决策复杂性，生成式人工智能与ABM的融合进一步提升了模拟的的分析与预测能力。Prateek Puri等人（2024）开发的模拟框架结合代理建模与自然语言处理技术，通过“数字克隆”技术复现真实传播网络，并引入语言变异模型，模拟信息在传播中的内容演化[ ]。Isabel Murdock等人（2024）聚焦于跨平台信息传播，构建了一个综合Reddit与Twitter特性的代理模型发现，用户在多个平台间迁移会削弱单一平台治理措施的有效性[ ]。
LLM的出现也为微观行为建模提供了突破路径。Javier Pastor-Galindo等人（2024）提出以生成式人工智能为核心的代理框架，利用大型语言模型（LLM）构造具有人类行为逻辑的代理，从而更真实地模拟社交网络中的互动与舆论演化[ ]。Park等构建的“生成式主体”通过LLM模拟人类日常决策，展现了自然语言驱动社会仿真的潜力[ ]。Gao等的S3系统则利用LLM主体模拟社交网络中的性别歧视议题，验证了模型在复杂社会场景中的适应性[ ]。Liu等基于LLM的多主体仿真研究了个体对虚假新闻的态度演变[ ]。基于LLM的假新闻传播仿真系统，构建具有个性特征的代理，分析不同群体对假新闻的反应与传播行为发现，政治类假新闻传播速度最快，且早期干预尤为有效[ ]。
因此，ABM与生成式人工智能相结合的社会模拟仿真，为数字信任的路径研究提供了从现象描述到机制预测的升级路径。与传统研究方法相比，其优势在于能够捕捉复杂系统的动态特征、探索个体微观行为如何演化为群体宏观现象，并评估多种干预策略的效果。在此背景下，本研究提出研究问题：

四、研究设计
真实数据研究受限于传统方法对数字信任动态测量的不足，且大规模动态追踪困难，无法对同一用户在不同虚假信息传播事件中的信任变化进行纵向追踪，缺乏个体层面的时序数据。为弥补这些局限性，本研究借助LLM代理构建起可控的社会模拟环境，具体表现为：（1）能够精确控制用户关系结构，包括强、弱、无连接，以及控制不同的社区管理策略；（2）可动态测量数字信任量表得分，进而捕捉数字信任随时间的连续变化；（3）通过重复实验来验证因果机制等。
（一）连接的定义及公式
因用户同时存在互关与单向关注，易导致的类型的区分模糊，本研究通过CV量化互关关系的相对占比，避免混合关系干扰。具体如下：
（1）互关数（Mutual Connections，M）：指用户与其他用户之间双向关注的数量（即A关注B，且B关注A的关系数）。
（2）总连接度（Degree，D）：指用户在社交网络中的总关系数，包括双向互关与单向关注（无论出度或入度）。具体计算为：D = M + Uout+ Uin
其中：Uout为用户单向关注他人（未被回关）的数量；Uin为用户被他人单向关注（未回关对方）的数量。
（3）连接值（Connection Value，CV）公式：CV = \frac{\mathbit{M}}{\mathbit{D}}（D >1）
强连接：当CV > 0.2时，即互关数占总连接度的20%以上，表明用户关系以双向互信网络为主；
弱连接：当0 < CV ≤ 0.2时，互关数占比不足20%，关系以单向关注或稀疏互动为主；
无连接：当CV = 0时，用户无任何互关关系M = 0 。
强连接对应微博中“互关好友”场景，用户间信任度高，互动频繁；弱连接对应“单向关注”场景，如粉丝关注大V但未被回关，关系具有信息不对称性；无连接对应陌生人网络，用户间无直接关注关系，依赖平台规则建立互动。

（五）实验流程与测量
1. 流程设计
（1）阶段1：初始化LLM代理关系网络
设定“tick”为基础时间单位，1个tick=2小时；总实验时长为120个tick（240小时，共10天）。
用户关系结构：
定义标准化：严格按互关关系划分用户组（按CV值划分强 / 弱 / 无连接），确保分组逻辑一致。
样本均衡性：在Society Zen Universe平台模拟中，为每组生成相同数量的用户代理（如各100个），用户属性基于现有用户做初始化，避免其他因素干扰。
数字信任：
指标一致性：每个tick进行数字信任的测量采用相同量表，避免测量偏差。
动态监测：在模拟周期内，按固定时间间隔记录数字信任变化，确保数据采集频率一致。
控制其他干扰变量：
模拟环境一致性：所有组在相同的模拟参数下运行，仅改变用户的关系结构和社区管理策略。
LLM代理一致性：所有Agent需预设统一的初始行为规则，避免个体差异干扰信任测量。
重复实验设计：每组实验重复50次，通过取平均值降低随机误差，确保结果稳健性。
核心观测指标：
个体信任差值（ΔT_agent，t）：表示Agent在第t个tick的信任差值，衡量其信任度相对于初始状态的变化（正值表示信任提升，负值表示信任下降）。公示如下：
ΔTi = Mt－M0
其中，i为Agent的编号，t为tick数。
群体平均信任差值（ΔT_group，t）：对每组（如强连接、弱连接、无连接实验组及对照组）内的所有Agent，计算每个tick的平均信任差值。公示如下：
{\mathrm{\Delta T}}_{group,t}=\frac{1}{N}\sum_{i=1}^{N}{\mathrm{\Delta T}}_{{agent}_i,t}
其中，N为组内Agent数量（1000个），{\mathrm{\Delta T}}_{{agent}_i,t}为第i个Agent在第t个tick的信任差值。通过求平均值消除个体差异，反映某一组别在第t个tick时的整体信任变化趋势。
（2）阶段2：注入同等量级虚假信息
信息标准化：向所有组投放相同类型、数量和初始传播特征的虚假信息（如相同文本内容、首发节点数量），控制信息源变量。
传播参数统一：设置相同的传播规则，确保传播动力学模型在各组间可比。
虚假信息传播与信任值关联：每个tick中，虚假信息的传播概率需与Agent当前信任值挂钩（如信任值越低，传播虚假信息的概率越高），形成联动的反馈机制。
（3）阶段3：按组别启用对应管理策略，持续模拟120个tick（240小时，10天）
干预时机同步：所有策略均在虚假信息首次传播后的同一时间启动，确保不同策略的时间变量严格可控（如起始时间一致）。
策略标准化：在3组实验中，AI判定、社区管理员审核、众包举报三类策略的核心机制保持一致。
（4）阶段4：每2小时采集数字信任三维度量表数据
每个tick结束时，对四组（对照组+实验组）共1,200个LLM代理发送指令，要求每位Agent根据真实感受回答数字信任量表，记录每组初始信任均值（M0）与标准差（SD0）。

3. 数据收集
Agent个体：记录其在不同时间节点（Tick-0、Tick-1、Tick-2等）的数字信任度量值（M0、M1、M2），并计算相邻时间点的差值（ΔT1=M1-M0、ΔT2=M2-M0），以此追踪个体信任随时间的动态变化。
组内纵向对比：分析各实验组（如强连接、弱连接、无连接组）在不同时间点的整体数字信任变化趋势（ΔT_group，t），观察数字信任衰减或回升的速率及拐点。
组间横向对比：聚焦同一时间点下各组的信任差值变化，通过量化不同关系结构或管理策略对信任演化的影响差异，揭示用户关系网络与数字信任动态的交互机制。
