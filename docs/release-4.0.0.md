# Society0 4.0.0 发布说明

4.0.0 将可恢复检查点切换为增量持久化格式。运行状态按声明的持久化语义写入，检查点只发布已经完整提交的 step；恢复、分支和直接 Tick 恢复均从同一套增量存储读取。

本版本同时保留 Agent Thread 与记忆纪元的配对关系。启用记忆时，检查点引用已经提交的记忆纪元，并继续使用同一 Chroma 视图；恢复过程不会复制数据库，也不会把未提交的记忆写入可恢复状态。

记忆读取仍可在主体调用中默认开启；持久记忆写入改为显式的 Thread 提炼步骤。明确要求主体为后续互动保留的信息会进入提炼约束，提炼结果、稳定记忆 ID 与提交回执共同留在原 Thread 中。

OpenAI 兼容嵌入端点新增 `send_dimensions` 选项。固定输出维度、且不接受 `dimensions` 请求字段的模型可将其关闭；Society0 仍使用声明的维度校验返回向量并记录运行信息。本版本已通过 `BAAI/bge-m3` 的真实写入、召回及并发测试。

社交网络环境的帖子状态已经使用“创建事实、互动事实、当前投影”三层结构；帖子向量查询同时遵守 Tick、分支与记忆纪元可见性。单分支查询不会再产生 Chroma 不接受的单元素逻辑过滤条件。

3.x 检查点不由 4.0.0 恢复。需要继续旧实验时，应继续使用冻结的 3.x 运行环境；新实验从 4.0.0 重新建立父世界。
