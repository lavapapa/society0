# 从这里开始

这一节带你完成第一次 Society0 运行：让两位规则主体在两个业务时点各作一次决定，再把它们留下的表读出来。全程只用本地 Python，不需要模型账户。走完这条路线，你会看到一个真实运行长什么样，然后就可以按自己的研究目标决定往哪边走——写自己的规则、加资料和行动，还是接入模型主体。

## 先按顺序走完这三页

所有命令都在源码仓库根目录执行。

1. [安装](installation.md)：取得与本文档相同的 Next 源码，建立 Python 环境。
2. [第一次运行](quickstart.md)：运行 Alice 和 Bob，读取第 2 步的决定表。
3. [最小概念地图](concepts.md)：把刚才跑过的工厂、主体、阶段和结果连起来。

准备 Git、Python 和终端就可以开始。存储支持 macOS 与 Linux 的本地文件系统，完整平台与构建身份见[版本信息](version.md)。每次尝试换一个新的运行目录，前一次的结果和失败线索就能一直留在原处。

## 第一次运行之后往哪走

完成第一次运行后，按自己的目标进入[教程](../tutorial/index.md)。

| 你想做什么 | 从哪里继续 | 需要的资源 |
| --- | --- | --- |
| 写出自己的规则实验 | [运行计划](../tutorial/first-plan.md) → [主体](../tutorial/actors.md) | 基础安装 |
| 让主体相互交流 | [轮次对话](../tutorial/conversation.md) → [信息读取](../tutorial/files.md) → [行动](../tutorial/actions.md) | 基础安装 |
| 了解模型主体如何工作 | [模型驱动](../tutorial/llm.md) → [记忆](../tutorial/memory.md) | 离线组合例子使用可选依赖；真实服务另行配置 |
| 检查与继续已有实验 | [结果](../tutorial/results.md) → [恢复](../tutorial/recovery.md) → [观察](../tutorial/observation.md) | 一份已经保存的运行 |

各教程标明完整程序与装配片段。复制完整程序可以直接执行；装配片段用于修改该页明确指出的已有程序。

## 需要查资料时走哪条路

学习途中要弄清边界，读[概念专题](../concepts/index.md)。已经知道目标、准备动手完成一项具体任务，查[操作指南](../guide/index.md)。需要某个参数、返回值或异常，查[接口参考](../reference/index.md)。

现在从[安装](installation.md)开始即可。
