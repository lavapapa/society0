# 概念与边界

这些页面解释运行中的职责、身份和时间如何对应。可以从自己遇到的问题进入；首次学习的操作顺序见[教程](../tutorial/index.md)，具体参数见[参考](../reference/index.md)。

## 一、构造一个共享世界

- [共享环境与机制](environment.md)：为什么两个对话平台可以共享主体，又分别维护自己的事实？服务依赖与数据依赖怎样配合？
- [主体与激活](activation.md)：一个持久主体怎样获得一次临时 Session？步骤、业务时间和 Moment 分别在哪里使用？
- [并发的三个层次](concurrency.md)：主体并行、请求并发和进程计算各解决什么问题？

## 二、主体知道什么

- [完整会话与增量认知](cognition.md)：已经提供的材料怎样保留？新材料的位置和呈现确认如何保存？
- [信息、授权与分页](information.md)：发现、读取和执行的资格怎样区分？游标为什么会过期？
- [记忆与检索](memory.md)：经验、写入时间和可重建索引怎样关联？三种记忆行为如何分别配置？

## 三、判断一次运行留下了什么

- [完整步骤与恢复](complete-steps.md)：当前状态、完整点、可执行分支和只读分析分别支持哪些操作？
- [仿真与研究证据](research.md)：规则与模型假设如何进入实验？软件闭环和经验结论分别需要什么依据？

这些边界会影响具体研究设计。例如，开放等待可以允许步骤结束，未完成决定默认阻止发布；预览推荐和真正呈现给主体也有不同效果。带着一个实际消费者问题阅读专题，随后沿文末指南完成装配即可。
