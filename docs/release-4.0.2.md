# Society0 4.0.2 发布说明

4.0.2 减少大型世界在增量持久化开启后的运行成本。可替换实体在一个 Tick 内连续更新多个字段时，只登记被修改的持久化锚点，并在 Tick 成功封存时复制和校验最终值一次；同一路径的持久化规则解析结果也会在运行期间复用。追加事实仍在写入前完成复制、类型校验和重复编号检查。

Agent Thread 的长期记忆写入现在允许跨 Thread 合并底层向量计算。每个 Thread 仍先保存自己的记忆待提交记录、稳定记忆编号和最终回执；共享的嵌入请求只记录参与的 Thread 与 Agent 编号，不会把批量原文写进某个单独 Thread。

新增显式分叉入口：目标运行保留自己编译出的世界状态，同时继承来源完整检查点的 Agent 认知历史和已提交记忆。分叉会核对嵌入模型身份、Agent 集合及身份字段，来源必须是完整的 v4 检查点。

4.0.2 沿用 `complete_step_v4` 格式，可以恢复 4.0.x 生成的完整 v4 检查点；3.x 检查点仍不受支持。
