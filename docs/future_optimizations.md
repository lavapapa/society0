# 未来优化任务清单

## FoV 机制优化

### 1. 批量 FoV 调用支持
**描述**：支持 FoV 函数一次性处理多个 agent，减少重复计算
**当前状态**：每个 agent 独立调用 FoV 函数
**预期优化**：
- FoV 函数签名扩展为 `(agents: List[Agent], env) -> Dict[agent_id, result]`
- 自动检测 FoV 函数是否支持批量处理
- 向后兼容单个 agent 的 FoV 函数

**复杂度评估**：中等
**优先级**：低

### 2. FoV 结果智能缓存
**描述**：在特定条件下缓存 FoV 结果，避免重复计算
**当前状态**：每次都重新计算 FoV
**预期优化**：
- 基于 agent state + env state hash 的缓存机制
- 支持 FoV 函数标记自己的缓存策略
- 缓存失效策略（基于依赖的 state 变更）

**复杂度评估**：高
**优先级**：低

## Action 系统优化

**优先级**：中

**预期功能**：
- Action 依赖声明语法

- 循环依赖检测

**复杂度评估**：高
**优先级**：低
