# Society0 4.1.14

## 推荐与记忆视图

社会网络环境直接复用完整步骤的只读记忆 epoch 集合。生成帖子向量元数据与可见性过滤继续沿用相同提交边界。

推荐运行期索引在初始化或恢复时重建；新增帖子、互动和投影由规范写入器更新。日常时间推进在已有近期、生命周期和互动榜候选上评分。候选正文保留完整互动与原文，全部创建及互动事实继续保存在原生检查点。

互动榜采用 sortedcontainers 的有序容器，声明固定依赖，支持既有正负分值与相同的并列排序。重复点赞计数遵循原始历史视图。显式事务把运行期索引更新放在提交之后，回滚取消回调；并发事务的每条互动使用规范 append 的实际提交位置。运行期派生更新失败会失效相关索引并记录错误，已提交事实保持成功，其他派生回调继续执行。

## 验证范围

确定性全量、两种状态访问模式、完整检查点、恢复、Thread 和记忆测试保持通过。同一原生完整点覆盖一千、一万、十万条历史记录，比较连续八步的候选顺序、正文、互动、分数及恢复事实。

完整 World 与 Thread 历史仍遵循原有驻留和上下文语义。此次改动减少推荐派生对象的复制与重复扫描；历史事实本身的空间需求继续随数据量增加。

默认语义召回的近期帖子沿作者发布索引读取，近期互动按时点、规范帖子顺序、互动类型与原始事件顺序读取。偏好文本保留原来的数量、正文与排序。配置改变后从已提交事实重建一次索引，随后继续增量维护。

按 ID 查询互动与详情时，仅读取所选帖子的完整事件；显式事务另包括自己的未提交尾部。主体资料计数、最近原文和发布向量资格使用当前索引或投影。
