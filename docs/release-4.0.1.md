# Society0 4.0.1 发布说明

4.0.1 修复跨目录恢复时长期记忆没有进入新运行的问题。恢复目标在模型、能力和应用合同身份校验通过后，一次性继承来源运行的 Chroma 逻辑库；后续 checkpoint 仍只发布增量状态和已提交记忆写入 epoch，不会在每个 Tick 复制向量库。

新运行的根检查点会保留来源 checkpoint 的记忆目标 Tick、分支谱系和已提交写入 epoch。这样，恢复后的 Agent 在第一次激活时即可查询来源运行中已经提交的记忆，后续写入仍由新运行自己的提交边界管理。

4.0.1 与 4.0.0 使用相同的增量持久化格式。3.x 检查点仍不受支持。
