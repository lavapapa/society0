# 研究模式

这份 reference 用于“有大现象，但还没变成具体实验”的阶段。下面的模式是起点，不是保证每个环境都已内置。先选最简单的模式，让研究机制可见。

## 传播、平台与可见性

问题形状：

```text
推荐、背书、关系或可见性规则，如何改变信任、极化、沉默、扩散或误解？
```

从这些开始：

- 环境：`social-sqlite`，或从它复制后改 `social`、`social-recommendations`、`social-ranking`、`social-perception`。
- 主体：LLM 读者、分享者、意见领袖、潜水者、版主；可加规则账号做基线。
- 可见范围：推荐流、热帖、通知、来源标签、好友背书、帖子原文。
- 行动：`social.publish`、`social.reply`、`social.repost`、`social.react`、`social.follow`、`social.unfollow`、`social.preferences`，以及不行动。
- 测量：立场分布、信任评分、分享意愿、跨群体暴露、理由文本。

最小实验：两到三种信息条件，6–20 个主体，5–10 个 tick，先看一条曲线或一张对照表。推荐研究要报告推荐池、评分权重、剪枝阈值、展示条数和曝光记录。

## 访谈、问卷与审议

问题形状：

```text
不同人格、暴露或对话伙伴，如何改变回答、理由或审议结果？
```

从这些开始：

- 环境：`plain` 用于第一版问卷或状态原型；需要配对和轮次时用 `social` 的配对配置和 `round-robin`。
- 主体：LLM 参与者，人格清楚；协议要求确定时可加规则主持人或规则记录员。
- 可见范围：刺激材料、伙伴消息、上一轮摘要、当前对话上下文。
- 行动：测量用结构化提交；行为用明确的发言、评分、排序、投票、修订或提交声明。
- 测量：结构化题项、定性理由、消息、排名、投票和最终声明。

最小实验：一个刺激、两到三种参与者、一个测量 schema、重复运行。需要和人类基准或效度检查比较时，先写清比较口径，不要把模拟回答直接当成人类样本。

## 治理、制度与权限

问题形状：

```text
规则、权限、制裁或公开信号，如何改变表达、合规、合作或合法性判断？
```

从这些开始：

- 环境：自定义插件或 `plain` 加规则阶段，直到权限、聚合和执行规则稳定。
- 主体：公民、平台用户、管理员、组织、观察者。
- 可见范围：公告、执行结果、可见的同伴行为、资源或身份变化。
- 行动：发言、合规、举报、审核、分配、申诉、退出。
- 环境约束：禁言、资源访问、角色权限、处罚状态。
- 测量：表达率、合规率、信任、合法性判断、处罚分布。

最小实验：一个政策变化、一个对照条件、一条可见的执行记录。先写清权限、聚合、执行和记录，再写人格。

## 组织、市场与经济

问题形状：

```text
角色差异、信息访问、工具使用或市场规则，如何改变协调和决策结果？
```

从这些开始：

- 环境：`plain` 做受控原型；当报价、库存、预算、税、银行或工作流成为核心时再写自定义插件。
- 主体：消费者、工作者、企业、助手、管理者、银行、监管者。
- 可见范围：当前报价、可选商品、价格、库存、公开指标、历史结果。
- 行动：购买、工作、推荐、排序、谈判、批准、拒绝。
- 测量：命中率、平均轮次、分配效率、价格变化、失业、满意度。

最小实验：一个有边界的任务，例如推荐助手能否在固定轮次内找到隐藏目标商品。价格、库存、折扣、预算、支付和交易有效性是环境机制，不是主体叙述。

宏观经济研究先用规则主体把会计和结算跑通，再在需要解释、预期或语言判断的地方加入 LLM 主体。

## 教育、课堂与学习

问题形状：

```text
教师支架、同伴关系、课堂场景或教育干预，如何改变学习痕迹、误解、参与或归属感？
```

从这些开始：

- 环境：`plain` 做一节课或一次辅导；需要课程图、分组、课堂网络、评估或可复用课堂记录时再写自定义插件。
- 主体：有可变学习状态的学生、教师/辅导者、同伴领袖，或规则评估基线。
- 可见范围：课程材料、学生上一轮回答、教师反馈、同伴消息、小组工作、评估题。
- 行动：提问、回答、解释、提示、挑战误解、分组、邀请同伴、支持、排除、提交作业。
- 测量：掌握度、薄弱概念、误解持续、参与度、同伴关系、评估分数、教师反思。

最小实验：一个主题、一位教师、3–8 名学生、一张误解表、一次课后痕迹检查。

## 法律、司法与犯罪

问题形状：

```text
法律、法院、执法、法律成本或法律援助，如何改变合规、求助、权利保护或规避？
```

从这些开始：

- 环境：当法律登记、案件、诉讼成本、法律援助或执法状态需要跨轮保留时，写自定义插件；`plain` 只适合很小的封闭情境。
- 主体：受影响个人、权力持有者、企业、居民、法官、立法者、执法角色。
- 可见范围：当前模拟法律、个人损害、可见裁决、法律选项、诉讼成本、信任或透明度信号。
- 行动：合规、违规、起诉、寻求法律援助、抗议、罢工、举报、裁决、执法、修法。
- 测量：行动分布、诉讼数、未满足法律需求、裁决、法律变化、福利、权利保护、合规。

最小实验：一个封闭争议、一张现行法律表、一个案件列表、一个月度法律审查阶段。输出保持研究用途，不提供法律建议、真实个人风险评分、执法建议或规避指导。

## 公共卫生、风险与健康行为

问题形状：

```text
公共警告、健康风险信息、脆弱性、社会关系或干预，如何改变态度和保护行为？
```

从这些开始：

- 环境：`plain` 做信息/态度试点；当危险阶段、资源、脆弱性或网络扩散是核心时写自定义插件。
- 主体：居民、患者、照护者、官员、社区骨干、脆弱群体。
- 可见范围：官方警告、本地风险状态、新闻、同伴消息、政策激励、资源可用性。
- 行动：分享、讨论、求助、帮助邻居、采取保护行动、延迟、拒绝、遵守、留下、离开。
- 测量：态度分布、保护行动采用、未满足需求、信任、风险感知、按脆弱性分层的结果、风险信息扩散。

最小实验：一个风险场景、一个干预/对照、10–20 个主体、热身阶段、明确的暴露记录。输出保持研究用途，不提供医疗建议或公共卫生政策建议。

## 城市、社区与突发事件

问题形状：

```text
公共警告、本地情境、移动约束和社会关系，如何影响共享事件下的行为？
```

先谨慎：地图或城市专用环境可能需要自定义插件。如果地理不是第一版的核心机制，先用 `plain`。

- 主体：居民、官员、服务人员、脆弱群体、社区领袖。
- 可见范围：官方警告、社区状况、家庭或工作消息、资源状态。
- 行动：移动、避难、分享信息、求助、提供支持。
- 环境约束：位置、移动能力、资源访问、风险状态。
- 测量：合规、移动、未满足需求、谣言扩散、对官方信息的信任。

最小实验：两个社区、一种警告策略、一个移动或资源约束。

## 国际关系、危机与安全

问题形状：

```text
有限的外交行动、沟通、战略不确定性或历史情境，如何影响升级、克制、联盟形成或危机稳定？
```

保持高风险边界：只做研究计划、机制探索、历史解释、稳健性检查或安全评估。不产出可操作的军事建议、冲突预测、瞄准、规避或政策建议。

- 环境：危机状态、关系图、固定行动 schema、严重度标签、公开/私下消息、动态变量和停止规则；`plain` 只适合很小的抽象策略游戏原型。
- 主体：LLM 国家/代表/游戏主体负责解释和沟通；规则主体或固定策略做基线。
- 可见范围：自身资料、允许行动、公开和私下消息、先前行动、可见关系状态、游戏期限或局部历史材料。
- 行动：发送消息、提出协议、接受/拒绝、等待、降级、在抽象游戏中选择攻击/不行动，或提交安全/风险分类。
- 环境约束：有效目标、行动严重度、可见性、回合顺序、终止行动、危机时钟、关系更新和非操作场景边界。
- 测量：升级分数轨迹、首次极端行动、联盟图相似度、条约/消息数、危机持续时间、攻击时点、提示/温度敏感性、理由分类。

最小实验：先用只有 `attack`、`do_nothing` 和可选公开消息的抽象安全困境，再考虑更丰富的情景。

## 选择规则

- 第一版的问题是测量，不是环境复杂度：用 `plain`。
- 可见性和扩散就是机制：用 `social`。
- 互动协议就是机制：用配对配置和 `round-robin`。
- 可见范围、行动、环境约束或记录会跨步骤复用：写自定义插件。
- 高风险领域：先做抽象或历史研究脚手架，保持行动面粗糙、类型化、可审计、非操作。
- 教育、法律、公共卫生和市场领域：先做可检查状态和记录的小规模试点，再扩大；这些领域的结论需要外部验证。
