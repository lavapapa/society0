# 与 society0-workbench 交接

正式使用开始即发现并加载最新版 `society0-workbench`，按其快速起步指引打开工作台。已克隆源码可从 `$SOCIETY0_REPO/skills/society0-workbench/SKILL.md` 发现入口；独立安装保持完整目录。后续复用同一工作台，按其低成本更新路径持续维护。

主 Skill 负责当前研究内容及其确认状态：推荐主体、环境、机制、研究问题、世界比较、来源，以及后续真实运行与结果。快速起步后，读取工作台 Skill 的“接入新资料”任务所列的数据合同与导入指引，直接复用本轮设计正文作为可阅读的设计资料。后续变更读取其“更新已有页面”指引，更新同一入口。每轮回复交付相应工作台版本，用户能查看完整设定、推荐理由与待确认项，摘要用于导读。用户修改后同步受影响内容；构建和运行阶段继续交接进度及结果。

具体接入格式、更新方法、合并粒度、刷新时机、组件与页面验收由 society0-workbench 的当前合同决定。主 Skill 使用其现有入口并核实更新回执，无需自行重建页面或维护第二套展示协议。简短汇报本轮已同步的内容；更新失败时保留当前方案与待同步差异，说明影响，继续等待本阶段的用户确认。

工作台中的候选、已选项、用户确认和真实运行事实保留各自身份。收到工作台返回的修改后，核对其对应方案；科学范围或预算变化回到相应确认阶段。页面打开、资料更新和参数提议本身不提供阶段确认或执行授权。

入口尚不可用时，说明接入缺项，保存本地设计稿及待交接内容；按主流程的确认停点推进讨论。恢复后按工作台 Skill 的合同同步当前稿。已有静态导出资产和测试保留独立消费者用途。
