# 与 society0-workbench 交接

正式使用开始即从宿主 Skill 目录或用户指定的可信项目入口发现并加载 `society0-workbench`。已克隆源码中若有 `$SOCIETY0_REPO/skills/society0-workbench/SKILL.md`，可从该入口读取；独立安装时保持其完整目录。按它的起步流程先建立可用页面，随后随设计和实际资料更新。主 Skill 负责实验设计、执行和解释，工作台 Skill 负责自己的展示与操作方式；安装、数据接入和页面验收遵循它的当前指南。

在基础设计初稿、用户选择确认、实验配置确认、运行状态变化和结果交付时，把当时真实的设计/配置/来源/运行工件引用交给工作台。传递内容使用对方声明的格式，核对其回执，保留未完成事项。

用户从工作台返回的选择或修改，仍需核对对应配置与当前实验是否一致；科学范围或预算变化回到主流程相应决定，已批准步骤继续自动执行。

入口尚不可用时，明确说明缺少 `society0-workbench` 接入，保存可追溯的本地设计与运行记录。继续不依赖它的、已授权的设计或计算；把工作台交接保持为待完成项，取得实际 Skill 后再按其合同接入。没有真实回执时不声称工作台已同步。

本指南不定义工作台 API、JSON 协议、CLI、页面布局或渲染流程。已有静态导出资产和测试保留其独立消费者用途，新的正式实验交接由 `society0-workbench` 指导。
