# 研究设计

## 从观察到实验

把日常观察翻译成研究脚手架：

1. 现象：观察到的模式或困惑。
2. 研究问题：要比较什么与什么。
3. 构念：哪些概念需要可测的代理变量。
4. 环境：平台、机构、媒体场或互动场景如何决定可见性和行动。
5. 主体：谁感知、记忆、行动并解释。
6. 干预与对照：条件之间到底改了什么。
7. 步骤循环：一个 tick 里发生什么。
8. 测量：哪些数值、回执和定性记录会被写入。
9. 有效性：需要哪些基线、重复、消融和敏感性检查。

问题模糊时，先沿三条机制轴拆：

- **信息与可见性**：谁在什么时候看到什么，顺序、推荐、制度过滤如何改变暴露。
- **制度与权限**：谁能行动，谁被限制，违规有什么后果，哪些行动留下记录。
- **主体与时间**：存在哪些异质群体，他们记得什么，一个 tick 在研究上代表什么。

## 方法立场

Society0 不是“传统 ABM 加一个更大的行为函数”。它是语言中介的多主体仿真：

- 主体行为可能依赖提示、人格、记忆、可见范围、模型提供方和可用行动。
- 它可以探索社会意义、解释、说服、信任、身份和平台可见性。
- 它不是直接的经验证据，而是需要稳健性检查的模拟证据。

从 ABM 借用的部分：

- 明确机制。
- 透明假设。
- 基线与对照。
- 重复运行。
- 敏感性分析。
- 机制探索与经验主张分开。

## 证据边界

在扩大设计前，先说明：

- 手头材料支持什么、不支持什么。
- 哪些说法会超出材料。
- 哪些实体能感知、决定、行动、承担后果。
- 哪些实体只是资源、记录、机构、地点、话题、图节点或流程位置。
- 即使把所有 LLM 主体换成规则主体，环境仍必须执行哪些后果。
- 哪些判断真的需要语言、记忆、解释、规划或社会意义。

这一步能防止两个常见错误：把领域图里的每个对象都变成主体；把宏观结论直接写进微观主体的提示或可见状态。

## 环境先于主体

先写清社会情境：

1. 模拟的是什么场景？
2. 每个参与者能看到什么信息？
3. 在这个场景里可能做什么？
4. 这些行动留下什么痕迹？
5. 实验条件的哪些部分必须隐藏？
6. 哪些指标和定性表可以从运行中恢复？

一个可用的环境设计可以写成：

```text
场景 -> 可见范围 -> 行动 -> 环境约束 -> 记录 -> 测量
```

只有在这之后才展开主体集合。主体的意义来自它被放在具体的可见性和行动结构里。

## 规则主体与 LLM 主体

LLM 主体适合：

- 解释消息、访谈和问卷。
- 说服、信任、情绪、身份、意识形态。
- 依赖记忆的行为。
- 自然语言互动。

规则主体适合：

- 确定性基线。
- 已知机制。
- 平台或系统角色。
- 参数扫描中需要排除模型波动的部分。
- 测试和诊断。

强研究常用两者：规则基线说明环境本身会产生什么，LLM 层再说明语言判断增加了什么。

## 最小可行实验

先做能产生一个可解释曲线、表或定性对照的最小运行。不要一开始就做完整城市、经济或上千主体，除非更小的运行已经验证：

- 环境状态能按设计更新。
- 可见范围展示的是预期材料。
- 行动集合窄到可以审计。
- 输出 schema 能稳定解析。
- 指标能回答研究问题。

第一个可解释运行之后，一次只加一层：主体异质性、更丰富的可见范围、记忆、重复运行、条件矩阵，最后才是规模。

## 隐藏条件与主体状态

- 人格文本要具体，但不要塞满无关心理特质。
- 主体状态用于需要随 tick 变化的少量数值或分类变量。
- 研究者标签、分组和条件分配放在研究侧，不要进入主体可见状态。
- 如果主体不应知道自己属于处理组，就不要在人格或状态里写 `condition: treatment`。
- 测量得到的变量只有在后续机制真的依赖它时，才写回主体状态。

## 时间与 tick

一个 tick 不是自动等于一天、一小时或真实时间。用研究语言定义它：

- 一次信息浏览。
- 一轮对话。
- 一个舆情周期。
- 一个政策阶段。
- 一个季度。

很多研究用“冲击—适应—稳定”三阶段比真实日历更容易解释。每个阶段可以写成显式阶段，记录哪个阶段产生了哪些输出。

## 有效性检查

- **内部有效性**：条件之间是否只差一个因素；主体、数据、种子和测量是否固定。
- **构念有效性**：测量题项或行动回执是否真的对应研究概念。
- **外部有效性**：模拟场景和主体构成能推到哪类情境，不能推到哪类。
- **统计稳定性**：多个种子、重复运行、分布和失败样本。
- **机制可审计性**：结果能否从记录、回执、状态和测量表重算。
- **替代解释**：如果看到差异，还可能是什么造成的；下一次比较如何区分。

## 报告边界

模拟输出不是经验观测。报告里要分开：

- 设计事实：主体、环境、条件、测量。
- 运行事实：完成了什么、失败了多少、消耗了多少预算。
- 观察结果：结果变量的分布和差异。
- 解释：可能的机制、替代解释和下一步对照。
- 限制：模型、提示、样本、时间尺度和测量口径带来的边界。
