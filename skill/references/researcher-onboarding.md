# 从当前意图开始

仅在用户希望了解 Society0、学习原理或尚未决定任务时读取。用户已经给出实验问题、论文或运行目录时，直接进入主流程对应阶段。

## 选择起步路径

简短说明：Society0 让多个主体在有明确规则、信息和行动的环境中互动，观察机制与条件变化产生的结果。Skill 指导 Agent 设计和执行；Python 引擎实际推进世界。

用户尚无具体目标时提供少量入口，允许自然语言提出其他要求：

1. 我有一个问题，想构思仿真实验。
2. 我想先理解环境、主体和机制如何工作。
3. 我有论文或现实材料，想改编成实验。
4. 我有项目或运行结果，想分析、恢复或排错。

第一项转[第一轮设计](design-first-pass.md)；第三项加读[论文拆解](simulation-paper-distillation.md)；第四项读[运行与分析](run-monitor-analyze.md)。安装需求转[安装准备](installation.md)，保持安装和实验设计各自状态。

## 教学路径

每次讲清一个概念，用同一具体例子逐步解释：谁参与、看见什么、能做什么、环境怎样产生后果、怎样随时间推进、怎样比较结果。先说明用户可观察的现象，再引入插件、FoV、Action 或完整步骤等术语。

根据本次理解给出 2—3 个相关的下一步问题，用户可以任选或直接提出新问题。教学保持可中断；用户转为实验设计后进入正式流程，复用已明确的要求。

## 实验与资源

新实验在基础设计中完成范围和机制选择，在[实验配置](experiment-configuration.md)中确认世界、时间、模型、资源和执行授权。先核对已有环境；需要新凭据时引导用户通过可信提供方和本地授权环境设置，不在会话或配置工件中回显密钥。

费用按用户提供或核实的费率估算。按各阶段的激活主体、模型请求、输入/输出、记忆提取、嵌入和重试分别估计，优先使用代表性 pilot 的用量。未提供费率时明确金额未知，不用猜测当前价格延误设计。

估计值注明范围与假设；运行后用提供方实际用量更新，账户账单确认后才称为实付。用户选择较小规模时说明对实验解释的影响，保持选定信息与行动能力。
