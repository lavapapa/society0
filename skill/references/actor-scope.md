# 主体范围与扩展

确定主体范围、补充参与者或关系时读取。先展开与问题有关的世界，再选择模型的表示范围；主体的 Driver、状态与记忆实现见[主体设计](agent-design.md)。

## 一、从作用路径找到参与者

从用户关心的变化出发，检查谁承受冲击、谁掌握资源和决定、谁传递影响，以及谁提供替代选择。沿相关路径向上游、下游、竞争者、协作者或制度参与者展开，优先补足会改变反馈或研究结论的环节。

给每类候选说明加入理由：它带来哪种选择、约束、异质性或互动？分别列出已覆盖、待补和本题暂作背景的部分。来源材料出现的名单是起点；检索预算与试跑规模分别服务资料工作和执行安排，研究边界由问题及机制决定。范围较大时保留候选覆盖及缺口，给出分阶段扩展建议。

需要企业名录、画像或关系资料时，发现并加载用户提供的外部资料 Skill，交接研究范围、时期和会改变设计的主体/关系缺项，按其合同消费成果。资料查询、清洗及接口操作由该 Skill 承担；本 Skill 决定如何建模。入口尚未提供时沿用已有材料，标明待补项。

具名实体及关系保留来源和时点；模型设定的连接标为假设，尚未核实的连接保持未知。历史研究按当时可得资料设定信息边界。匿名或合成人口说明数量与分布依据，方案值保留其假设身份。

## 二、把候选转成可互动的世界

给出主体类型、角色、独立个体数量及完整名单或可复建的生成规则。以实际决策单元划分：机构、部门、家庭或个体各自拥有怎样的信息、裁量和行动？产品、设施与制度可由环境记录或机制表示。

选择表示方式时说明研究取舍：

- 独立主体保留会改变约束、信息、选择或互动对象的差异；同类个体可以独立互动。
- 聚合表示说明成员数量、权重及会丢失的差异。用一个行动放大多人行为，会引入同步性，需判断是否适合本题。
- 外部背景明确它提供的条件，以及哪些反馈留在本次范围之外。
- LLM 与规则驱动按所需裁量选择。改变已确认驱动、主体规模或信息能力属于方案修改，资源估计随方案说明。

每次增补连同关系一起设计，回答以下问题：

| 设计内容 | 应说明的变化 |
|---|---|
| 处境与初态 | 拥有什么资源、资格、能力或负担；哪些由资料支持，哪些采用假设 |
| 感知与裁量 | 能知道什么、决定什么；画像中的差异怎样进入信息、约束或选择 |
| 互动接入 | 与谁交易、沟通、竞争或协作；如何获得接触机会、承担行动后果 |
| 反馈与观察 | 它怎样影响其他主体及总体结果；哪些过程能够观察 |

保留原有主体标识与关系含义，指出新旧主体之间的依赖。研究者掌握的全局资料按各主体实际可见范围进入认知。行为偏好作为待检验设定，允许主体在情境中作出不同选择。

## 三、交付范围与变化

将三种规模分别说明，并注明时点和依据：

| 口径 | 含义 |
|---|---|
| 候选覆盖 | 已有资料实际覆盖的实体及仍待补的范围；计划覆盖量单列 |
| 设定纳入 | 当前方案中的独立主体、聚合成员及外部背景，各按自身单位计数 |
| 实际运行 | 指定运行实际装入的主体；需要时另列 LLM 驱动和已激活数量；尚未运行直接注明 |

向用户交付扩展理由、新增主体与互动、保留和遗漏的路径、资料缺口及推荐范围。首轮把取舍并入基础设定的同一组问题；已有方案按[设计修订](design-revision.md)确认受影响部分。详细画像补齐与输入编译在获准构建阶段完成。

**产业例子：**从已知电池企业展开到替代技术提供方、终端采购方与非上市配套企业，按技术替代、需求切换或供应约束说明纳入价值。外部资料 Skill 提供名录与依据；本 Skill 判断参与者的决策边界和关系表示。某候选尚缺交易关系时，保留未知或提出明确的连接假设。

**教育例子：**在学生与教师的设计中加入家长，先解释家庭资源、可见反馈和干预选择如何进入过程，再决定每户独立表示或按研究所需差异分组。学生人数、家庭数量与家长主体数各有口径，新增主体与其信息权限一起确认。
