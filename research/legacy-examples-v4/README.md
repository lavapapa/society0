# 旧版示例

本目录保存旧 `Society0`/`World` 入口的两个原始示例，来源为提交 `6c25d37dded062699347e595ca998ac4cad5530e`（Society0 4.0.2）。它们依赖该版本的代码与产物合同。需要复现时，在原版本检出其原始 `examples/` 路径后按该版本说明运行。

现行研究从 [第一次运行与恢复](../../docs/core-next/getting-started.md) 开始，当前示例集中在 [examples/core_next](../../examples/core_next)。旧接口退役关系见 [退役记录](../core-next/retirement-inventory-20261004.md)。
