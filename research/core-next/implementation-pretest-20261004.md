## 一、实现

模型适配采用 Pydantic AI 的低层 Model/EmbeddingModel，Society0 继续拥有主体循环、完整 Thread、行动与记忆。Authlib 和 JoseRFC 承担官方 Sign in with ChatGPT 的授权与身份处理，认证入口提供独立账户登录和刷新。首版订阅接入 Codex/ChatGPT；调用者取得聚合后的完整 Responses 结果，适配内部消费端点所需的流。SDK typed 消息保存其已识别的 opaque 内容、签名和工具 namespace，恢复后用于下一轮完整请求；展示投影可以在未安装模型 SDK 时读取。没有明确成功终态的工具片段保留诊断并结束为未完成。入口与完整主体示例见 [订阅指南](../../docs/core-next/subscription-guide.md) 和 [模型合同](../../docs/core-next/models-contract.md)。

权威状态继续使用 APSW/SQLite，Session 增量改为 zstd 压缩流。在线 Thread、结果和资源正文使用固定 64KiB 原始字节的独立 zstd 帧；冷数据批次由 SQLite 位置目录与 pyzstd seekable 正文组成，两份工件沿同一事务登记，并接通恢复、只读准备、导出及清理。原有压缩工作池和池参数已移除，当前格式为 3。同步 JSON 编码、压缩与写入的成本仍在规范 writer 上，变化的恢复格式需要在新测试阶段重新验收。

插件资源、步骤和主体固定 worker 改用 TaskGroup 收束。FixedStep 与 PhasedSchedule 共用 Runtime 的完整步骤边界。动态行动使用 SQLite FTS5 搜索模板并保留字面子串匹配、资格复核和稳定分页；共享信息挂载用 manifest、分页目录与分片呈现大资料，原文保留完整取得路径，私有工作区继续由 Bashkit OverlayFs 维护。HTTP 接入 Starlette/Uvicorn，活动请求容量与连接容量分别配置，继续提供状态、持久 tail 和只读完整视图。

可选 compute_plugin 用标准 ProcessPoolExecutor 提供一个运行内共享的计算服务，max_workers 和 max_pending 明确设置。图机制示例把紧凑图快照送入进程计算，并在结果返回时复核来源版本；权威修改仍由拥有者按业务顺序写入。任务数量额度不约束调用方已经构造的参数字节量，完整图投影仍承担完整输入和输出的 IPC 成本。公开工厂、两个新示例、安装说明与依赖锁已同步，依赖解析完成，未进行依赖安装及运行验证。

## 二、审查

实现由模型、存储和运行三个子任务完成，先交叉阅读调用链，再由未参与实现的智能体做最终静态审查。最终范围覆盖运行与插件生命周期、完整步骤发布、VFS、ASGI、存储及恢复、共享计算，以及模型—Thread—记忆的公共链路。当前未留下已确认且未修复的静态阻断项。

审查修复了未知用量被记为零、错误响应留证与缓存顺序、typed 正文被凭据脱敏改写、嵌入等待者取消后的资源收束，以及订阅记忆提取参数的问题。大正文投影的目录页大小下限设为 2，避免分层目录无法到达叶文件。阶段和安装器主动取消现在能唤醒拥有者并排空任务，重复取消不会再次穿透已有清理，清理函数自身取消会作为关闭失败传播。

最后对 27 份变更 Python 产品与示例文件进行 AST 语法解析，对 pyproject.toml 和 uv.lock 进行静态解析，git diff --check 无错误。这些操作没有导入或运行产品。本轮没有新增、修改或执行测试，也没有执行探针、基准、登录、LLM 或 embedding 请求。既有测试的历史通过记录对应原来的冻结源码。

## 三、规模

沿用选型阶段相同的物理行计数脚本，包含空行、注释和文档字符串。当前 Python 库 10,990 行，加 Rust 桥 286 行，共 **11,276 行**；原基线为 12,736 行，减少 1,460 行，约 11.5%。这高于原规划上限 10,500 行，共超出 776 行。原预算低估了账户认证、SDK 消息持久化、任务拥有者和有界文件投影仍需由应用承担的工作；此次保留实际消费者与完整语义，并明确记录预算差距。

工作台源码与构建入口 2,556 行、示例 782 行、研究者 skill 代码 316 行，加库后全部产品和使用代码共 **14,930 行**。库与工作台测试仍为 **15,419 行**，测试覆盖率尚未重新测量。原始逐文件统计见 [源码规模](implementation-pretest-size-20261004.json)，配置、锁文件、研究工件与文档未计入这些代码数字。
