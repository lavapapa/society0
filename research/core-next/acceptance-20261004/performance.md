# 同源完整输入性能验收

本轮比较既有真实原始输入的全部 1,448,471 条记录，保留原顺序、字段与原文，并在完整点恢复后逐值核验。原始 format 2 根仅作为输入，未给新产品添加兼容恢复。输入路径与原始命令在 execution-summary.json 和 Linux 执行工件中可追溯。

## 一、输入

旧消费者来自 /tmp/society0-core-next-20261004/cold-datasets-native-full-source，原始输入为同目录 v04-root；新消费者来自本任务 source 的最终共享帧实现。旧、新和被否决的 seekable/独立记录中间态分别使用新目录，未覆盖原始根。正式对照为 linux-performance-old.json 与 linux-performance-shared-final.json；两者 all_values_equal=true，记录数相同。新代码仅由既有 64KiB sink 提取 ChunkWriter，单值与批次共用，索引及范围定位由 SQLite 承担。

## 二、成本

旧 probe 内部完整流程 133.699 秒，新 134.100 秒，单次差约 0.30%；外层进程计时不混入该对照。旧导入 58.960 秒、恢复逐值验证 74.693 秒；新导入 59.695 秒、验证 74.364 秒。新源解码 29.137 秒、同步 JSON 编码 20.329 秒、原生压缩及有限缓冲 4.304 秒、SQL/控制 5.918 秒、显式 fsync 0.00667 秒。旧压缩计时未包含全部相同缓冲边界，分别保留原定义。新 complete 1.301ms、restore 4.572ms、只读准备 3.842ms，旧也在同一量级。

旧与新三个目录合并后的实际唯一分配空间均为 226,680,832B；恢复和只读视图共享不可变工件硬链接。新源码单工件，标准原生 zstd 共享帧保持与旧布局同量级压缩率。旧峰值 RSS 334,716,928B，新 340,480,000B，包含原始巨值解码及恢复逐值物化；单次差不证明内存改善。get 的全值物化仍随所请求记录增长，最大记录约 29.95MB。

100 个每次独立打开的小页：旧 0.02422 秒、被否决 seekable 1.7629 秒、最终 SQLite 0.02211 秒。seekable profile 的 19.664 秒中 19.343 秒是全部 seek 表构建，范围读取仅 0.063 秒；该根因由每个公开请求成本触发。独立记录压缩虽然小页恢复，却产生约 846MB 的空间，因此也被否决。两次反证保原始日志，最终合同保小读取与旧空间，而未依赖跨请求句柄池。

## 三、热路径

最终独立进程打开 1.262ms，1000 次固定小页 0.21269 秒，巨值内 64B 跨帧范围 0.373ms；峰值 RSS 28.31MB。20 次相同活动投影修改及完整点发布，Session 每次 2416B，首五步均值 1.261ms、末五步 1.009ms；恢复 12.579ms，字段和范围值保持一致。另一个只读进程顺序继续 1000 页、42,213 条记录，耗时 2.421 秒；1000 随机范围共3000个有界公开调用耗时0.499秒，拼接核对相等，峰值RSS28.22MB。均保 OS 缓存，没有声称物理冷盘成本。

真实 socket 回归反复创建新的 Observation/StageReader/Results/Datasets，固定目标与 10/5000 条无关历史对照，巨值引用页0帧、64B跨界2帧。页内共享帧只在本次读取期间通过标准 lru_cache(maxsize=1)复用，退出清空；全量尾读、跨块、来源删除、恢复及权限保完整消费者断言。当前增量成本由本步新增或修改字段决定，该有限20步证据不推算所有业务长跑。

## 四、范围

JSON 编码、压缩和规范 SQLite 写入仍在拥有者线程同步完成。ProcessPool 已实际承接独立 GraphEnvironment 投影，多消费者共享进程与在途额度，取消后排空；其用途与规范持久化成本分开。step-cost-current.json 的规则、LLM离线传输、记忆三个30步样本分别记录环境、模型、记忆、持久化和RSS；外部网络与真实向量服务不包含在该离线成本里。

该验收证明原值、恢复、空间及小读取回归已收敛。完整成本与旧布局接近，未获得整体加速证据；真实模型主体效果及整个现实运行链仍待有效免费端点与独立订阅登录完成。
