# 指定提供方的最终真实验收

本轮使用用户指定 SiliconFlow 的 Qwen/Qwen3.8-27B 与 Qwen/Qwen3-Embedding-0.6B，保留原目标、调用预算、完整历史及记忆合同。最终十五个场景各有成功行为证据，其中 VFS 使用既有成功运行工件纠正测试期望后离线验收。全部路径、逐场景判定及汇总数保存在 `final-report.json`，原先失败记录继续保留。

## 一、覆盖

最终映射为 chain-live-03 三项、remaining-live-01 中除被替代社交发布之外的八项、social-vfs-final-01 三项社交及其 VFS 工件复核一项，共十五个唯一场景。覆盖真实工具调用、并发与阶段容量、访谈、提取与嵌入、召回、完整边界、跨进程退出恢复、行动完成/拒绝、社交浏览与发布、多步运行、文件发现和结构化分页。

恢复主体明确答出 B42 与已收款 500 元，引用了已召回记忆；验收排除了 user 中出现字段和后置提取输出带来的伪成功。VFS 实际 completed，四页十二条数据完整，jq 复算 12/546，117 字节正文按两段原样拼合，提交保留源句号。旧 expected 删除句号与源冲突，修正后的唯一 oracle 直接取源正文尾串，真实测试及离线验证共用同一函数；无需再次发模型请求。

这是有明确源快照和修复范围的组合验收。社交正文路径与原生对象协议曾发生变更，故不描述为同一全新版本一次性十五项 pytest 全绿。Memory 三开关八组合的完备性仍由确定性测试承担；本轮真实运行及双分支对照覆盖其实际链路。

## 二、用量

`final-usage-manifest.json` 明确列出七组目录下的 28 个 current.sqlite。汇总包括完成运行、被替代运行及未完成诊断的实际请求；完整验收范围由上一节另列。237 条被选物理记录按类别和物理 ID 去重后为 191 次，共同恢复历史只计一次。同 ID 若事实不同，汇总程序会报错，避免静默选取。

校正累计流统计后的模型调用共 134 次，其中 133 个完整响应、1 个错误；已报告输入 263,474、输出 9,106、缓存读取 61,184 token。相同 133 个模型响应集合的 cache/input 比为约 23.22%，未混入嵌入或重复继承记录。超时调用缺少终态用量，其部分流统计不补入上述数值；因此这些是已报告量，无法直接推导全部计费。缓存写入全部缺失，继续记为未知。

对应嵌入共 38 次物理请求、38 次响应，已报告输入 996 token，输出与缓存字段缺失。逻辑消费者复用批次或缓存并不增加物理请求。早期 chain-live-01、round-live-02 共 18 次模型、1 次嵌入调用单列，依主控清单整体标为 usage_valid=false；其 token 聚合不加入新口径，也不用来比较速度或费用。

独立端点、短长缓存及 raw streaming 探针单列，未混进 SQLite 汇总。默认 streaming 曾把累计 usage 相加；成熟 SDK 的 continuous 设置已经由端点接受并应用，新运行正缓存值有实际证据。旧 90,112 缓存数字不再作为有效总量。所报比例属于这组实际调用，不能推广为固定缓存阈值或长期节省比例。

## 三、效果

两条 effects-live-02 分支来自相同源 step=1，顺序运行，仅自动召回开关不同，自动写入与主动记忆工具均关闭。关闭召回时，主体说明根目录无资料、无法提供订单与金额，并明确不猜测；开启召回时，主体明确回答 B42、500 元并引用召回原文。两支均 completed。只读复核输入显示关闭分支无 B42/500 召回消息，开启分支有原文 recalled_memories。

关闭分支新增两次模型请求，输入 3,207、输出 122；开启分支新增两次模型及一次嵌入请求，合计已报告输入 3,263、模型输出 111；两支新增缓存读取均为零。这些数值从运行后减运行前共同历史得到。该单次对照支持召回信息实际进入主体决策，尚不足以估计统计效果或长期记忆收益。

## 四、边界

旧 round 失败来自默认对象参数与字符串 schema 冲突；先前 browse 的 b 在空个人记忆上花费四轮，最后读到没有正文链接的帖子元数据后耗尽八轮；tail 的首个流式调用在约 60 秒中断，仅有不完整工具片段。其失败与诊断成本均保留。社交修复提供显式正文路径，后续原预算三例通过。VFS 保留原 assertion failure，同时记录精确源 oracle 的同工件通过。一次 effects 导入失败发生在网络前，代理 continuous 探针失败单独保留。

本轮证明指定提供方下的协议、工具、记忆、文件与完整恢复可用性。有限次数运行、进程受控退出和小型仿真不构成长跑可靠性、硬件断电恢复、任意规模性能或模型普遍有效性的保证；没有推算价格，也没有执行付费模型回退。最终发布还应由主控将确定性平台验收、文档及代码身份一并冻结。本报告完成研究验收记录，不代表 PyPI 发布。
