# 旧入口退役记录

新版公共入口、完整状态与主体交互已切换至 Core 和机制插件。旧实现以提交 `96b1f3b11aee3c146f5b43e0b8158ec29294e98a` 保留；逐项删除清单和新版语义锚点见 [机器清单](retired-test-map-20261004.json) 与 [能力矩阵](../../docs/core-next/capability-parity.md)。本记录说明源码整理范围，真实服务与最终交付验收由 V05–V08 分别留证。

## 一、范围

已移除 43 个旧产品 Python 文件、51 个旧 primary/performance 专属测试和三个旧端到端文件。旧 World、Society0、状态代理、旧环境注册与旧检查点读取接口从当前发行入口退役。新的真实套件覆盖原 13 项领域场景，另有独立进程恢复与 VFS 主体效果消费者；实际网络运行状态见对应任务证据。

共享的异步任务、激活池、strict 参数处理、资源管理与记忆提取协议继续作为产品资产。新内核使用这些实现，提供方工具字段、重试、限流、取消、超时及批处理直接测试继续运行。旧 AgentGroup 委托和旧 Thread 日志连接已移除。三项有效激活池测试保留于 `test_activation_pool_shared.py`。

## 二、对照

`tests/reference` 保存基线中 15 个原始算法；非作者逐字符核对证据为 [参考核对](builtin-reference-independent-source-20261004.json)。它们服务于轮次配对、图结构和推荐算法逐值比较，正式产品由新插件实现。

源码退役后的确定性全量为 648 passed、15 deselected，耗时 24.91 秒，见 [全量日志](retirement-deterministic-final-20261004.txt)。首次全量保留了 Workbench 同名阶段曲线合并的有效失败，该问题由负责人修复并独立复验。此数字绑定该次源码状态；后续产品变动应使用后续全量证据。

## 三、边界

接口已破坏性重设。完整消息、事实顺序、原始记忆、类型和信息可达性继续由实际消费者验证；旧 Python 对象别名和内部格式不作为兼容合同。公开源码采用单一新入口，旧运行只能由原版本读取。

两轮研究 starter 在召回提供方故障时使本次步骤失败，保留此前完整点；旧 starter 的静默忽略召回错误行为不再沿用。空的成功召回仍允许测量，并保留当前消息原文。这个区别保障因服务故障缺失的记忆不会被解释为正常无记忆条件，研究者可显式关闭自动召回来定义无召回实验。

完整退役关系可从机器清单回到基线及新版测试。当前源码可收集与确定性通过的证据，不替代真实端点、规模对照或独立最终审查。
