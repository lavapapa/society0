# 全根冷数据的连续分页与随机范围

此前独立进程的 1000 次页请求反复读取固定第一页。本次在同一个已转换的真实全根工件上追加顺序继续分页和随机范围抽样，源码使用已冻结的 native cold dataset 产品，脚本为 `benchmarks/core_next_dataset_access.py`，原始结果和执行命令分别在 `dataset-access-real-20261004.json` 与 `dataset-access-command-20261004.txt`。

## 一、访问

服务器独立 Python 3.12.9 进程以 StageReader 打开已有 1,448,471 条数据，只读执行，不修改运行。每页最多 100 条、完整响应最多 64 KiB，按上页返回 cursor 连续请求 1000 页，所有返回 ordinal 逐项检查连续无跳号。实际读取 42,172 条，最后 ordinal 为 42,171，响应合计 64,429,731 字节，墙钟 2.374 秒。巨值作为引用保留，因此每页不保证恰好 100 条。

随机抽取 1000 条，每条先读取 1 字节确认总长度，再选定随机偏移读取最多 64 字节，另取一个相邻窗口检查原文字节重合。共 3000 次公开范围请求、主样本实际返回 60,104 字节，墙钟 0.495 秒。该数字包括三次请求的身份校验、文件开关、定位和必要块解压，不能除以 1000 后称为一次范围请求延迟。

## 二、边界

两种负载合计墙钟 2.873 秒、进程 CPU 2.872 秒，独立进程峰值 RSS 22,843,392 字节。操作系统缓存保留，所有范围比较均通过。这里验证了固定响应预算与有界范围读取在更换页和随机目标后仍成立；结果不覆盖全历史导出、同时许多读者、完整巨记录读取或 Memory 向量索引驻留。

此次结果补充了真实分析访问路径，同时保留原固定第一页实验的准确口径。全部正文逐值等价已由全根导入验收单独验证，本轮不再次物化旧 JSON 或整个 World。
